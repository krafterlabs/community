# Contributing

Thank you for your interest in contributing to this community.

## Filing Issues & Feature Requests

This repository accepts **issues and feature requests only**. Please use the provided issue templates:

- [🐛 Bug Report](.github/ISSUE_TEMPLATE/bug_report.yml)
- [💡 Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml)

### Guidelines

- **Select your product** from the dropdown in the issue template
- **Be specific** — include reproduction steps for bugs, detailed use cases for features
- **Check existing issues** before filing to avoid duplicates
- **Be respectful** — see [Code of Conduct](CODE_OF_CONDUCT.md)



## What NOT to submit

- Source code or patches (this repository contains no code)
- Private or sensitive information (API keys, credentials, internal config)
- Pre-compiled binaries or large files (use the Releases tab instead)



## What happens next

Once you file an issue:

1. Our team will triage it and add a product label
2. If it's a bug, we'll investigate and work on a fix in the private product repository
3. When resolved, a fix will be included in the next release
4. You can track progress via the [public roadmap](../../projects)



## Questions?

If you have questions about a product, file an issue with the **question** label.

Thank you for your feedback!

# Community

Public hub for issue tracking, feature requests, and product releases across all Harshit's projects.

## What is this repo?

This is a **control plane repository**—it contains no source code. It serves as:

- **Issue tracker** for bugs and feature requests (unified across all products)
- **Release hub** for compiled binaries and assets from private product repositories
- **Public roadmap** (GitHub Projects) showing timelines for upcoming work

Your actual product code lives in private repositories and is never exposed here.

## How to report issues

Use the issue templates to file a bug or request a feature:

- **[🐛 Bug Report](.github/ISSUE_TEMPLATE/bug_report.yml)** — something is broken
- **[💡 Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml)** — suggest an improvement

When filing an issue, **select your product name** from the dropdown. This helps us route your feedback to the right team.

## Where to find releases

All product releases are published under the [Releases](https://github.com/krafterlabs/community/releases) tab of this repository, organized by product and version tag.

Download the pre-built assets for your platform from the release page.

Example release tags:
- `freehold-v1.0.0` — Freehold release
- `product-2-v2.1.0` — Product 2 release

## Roadmap & timeline

View the public roadmap at [Projects](https://github.com/orgs/krafterlabs/projects) to see what's being worked on and when features are expected to ship.
